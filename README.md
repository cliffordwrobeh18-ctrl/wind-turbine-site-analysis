# Wind Turbine Site Analysis

Python-based engineering project analyzing wind turbine performance and site feasibility using real weather data.

## Project Overview
This ENGR 1102 project used weather data and engineering calculations to estimate wind turbine performance and compare potential turbine locations.

The analysis included:
- Calculating air density
- Adjusting wind speed to turbine hub height
- Applying turbine cut-in and cut-out speeds
- Estimating turbine power and annual energy
- Comparing sites using transmission losses, profitability, and breakeven time

## Sites Compared
- Concord, California
- Sioux Falls, South Dakota
- Midland, Texas

## Tools and Skills
Python, NumPy, Matplotlib, engineering calculations, data analysis, renewable energy analysis, and technical communication.

## Key Equations
Air density: `rho = pressure / (R * temperature)`

Adjusted wind speed: `v2 = v1 * (ln(H2/z0) / ln(H1/z0))`

Turbine power: `P = 0.5 * Cp * rho * A * v^3`

## Result
Based on the course-project comparison, Concord, California was the strongest of the three evaluated sites.
